# Text-to-SQL Clarification Engineer

A production-oriented Text-to-SQL system that combines natural-language
database querying with a dedicated Clarification Engineer.

## Project Status

🚧 Phase 0 — Architecture & Engineering Foundation

## Goal

The system will eventually:

1. Understand natural-language database questions.
2. Detect ambiguity and missing information.
3. Ask clarification questions when necessary.
4. Understand relevant database schema.
5. Generate SQL.
6. Validate generated SQL.
7. Execute SQL safely.
8. Validate results.
9. Generate a grounded natural-language answer.
